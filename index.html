Panduan & Cara Penggunaan

DocuScript Editor • CreatorDock Studio

🎬 Selamat Datang di DocuScript Editor!

Aplikasi penulisan naskah dokumenter berbasis format dua kolom standar siaran (AV Script / Audio-Visual Script) yang siap digunakan di laptop maupun ponsel.

1. Arti Indikator Status Adegan (Dot Warna)

Klik titik warna di kolom kiri tabel untuk mengubah status adegan:

  • Hijau (Ready/Final): Adegan selesai, narasi & visual sudah siap diproduksi.
  • Orange (In Progress): Dalam proses pengerjaan atau butuh revisi narasi/materi.
  • Biru (SOT / Draft): Adegan potongan wawancara penting (*Sound on Tape*) atau draf awal.

2. Penulisan Naskah & Tag Otomatis

  • Edit Teks: Klik langsung pada kolom Visual atau Audio untuk mengetik.
  • Tombol Tag Cepat: Tempatkan kursor di dalam kolom, lalu klik tag seperti +[B-ROLL], +[SOT], atau +[VO] di atas tabel untuk menyisipkan format standar secara instan.
  • Estimasi Durasi VO: Sistem menghitung otomatis total kata naskah audio dan mengestimasi durasi pengisi suara (Voice Over).

3. Panel Riset & Transkrip

Klik tombol Riset di header untuk membuka panel catatan samping. Gunakan area ini untuk menyalin transkrip wawancara mentah atau catatan wawancara sebelum dimasukkan ke dalam tabel naskah.

4. Menyimpan & Melanjutkan Tugas

  • Tombol Simpan: Mendownload file naskah ke HP/Laptop dalam format file project .json.
  • Tombol Buka: Memilih file .json yang sudah disimpan sebelumnya untuk melanjutkan pekerjaan Anda kembali 100% utuh.
  • Cetak PDF: Klik tombol PDF untuk mengunduh atau mencetak naskah bersih tanpa tampilan tombol editor.
